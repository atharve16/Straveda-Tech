# STRAVEDA

The Git repository root is this directory. `source-code/client/` is the Expo SDK 58 Android application. `source-code/02-web-portal-source/` and `source-code/03-demo-data/` are reference inputs for local inventory and database verification; they are excluded from the EAS archive and are not required to build or run the APK. `documentation/` contains submission documents. `android/` is currently empty; no signed APK has been generated.

If reference inputs have been moved outside the repository, set `STRAVEDA_REFERENCE_SOURCE_DIR` to the PHP source directory and `STRAVEDA_DEMO_DATA_DIR` to the demo-data directory. Scripts also look in the current `source-code/` locations and the older root-level locations. Do not move these directories into the Android client.

From `source-code/client/`, run `npm ci --include=dev`, `npx expo install --check`, `npm run typecheck`, `npm run test:domain`, `npm run test:seed`, and `npm run check:offline`. The `production-apk` EAS profile uses project ID `1588b446-83d5-4a51-b162-d97e425ea5c6` and Android application ID `in.rohanenergy.offline`. The EAS root `.easignore` excludes reference material, caches, tests and documentation from the archive while retaining the bundled SQLite database.

To inspect locally without starting a cloud build, run `npx eas-cli build:inspect --platform android --profile production-apk --stage archive --output <temporary-directory-outside-repository> --force` from `source-code/client/`. See [build instructions](source-code/client/docs/BUILD_INSTRUCTIONS.md) for signing and release steps.
